โปรเจกต์สร้างเว็บไซต์ใหม่บน **WordPress แบบ self-hosted** สำหรับสมาคมเอ็นโดดอนติกส์ไทย — เป้าหมายคือเว็บที่ **สร้างจริงได้ทุกหน้า ปลั๊กอินฟรีทั้งหมด (ไม่มีค่า license รายปี)** และเจ้าหน้าที่สมาคมคนไม่เก่งคอมก็ดูแลเนื้อหาเองได้ทุกวัน

## 🎨 ทิศทางดีไซน์ที่สะสมไว้ (ให้กรรมการเลือก)

- **แบบ 01–10** — ชุดหลากหลาย (Nocturne, Bento, Newsroom, Congress Mode, Service Journey, TEA Pocket ฯลฯ)
- **แบบ 11–20** — ชุดทันสมัยพิเศษ (Glow Line, Soft Clay, Insight Dashboard, TEA Assistant, Mono Luxe, Color Field, Storyline, Card Deck, Lab Notes, Split Identity)
- **แบบจาก Stitch เพิ่มเติม (21–25)** — หน้าแรก, ศูนย์ดาวน์โหลดเอกสาร, ทำเนียบทันตแพทย์, งานประชุม/อบรม, หน้าสำหรับประชาชน

ทุกแบบระบุ **สูตรสร้างจริงใน WordPress** (ธีม/ปลั๊กอิน/บล็อก) และใช้โครงเนื้อหาชุดเดียวกัน — เปลี่ยนดีไซน์ทีหลังไม่ต้องกรอกเนื้อหาใหม่

## 💰 สรุปต้นทุนที่ต้องเสียจริง

| รายการ | ค่าใช้จ่าย |
|---|---|
| โดเมน | ~375–500 ฿/ปี |
| โฮสติ้ง (เจ้าไทยออกใบกำกับภาษี แนะนำ) | ~1,500–2,500 ฿/ปี |
| WordPress + ธีม + ปลั๊กอินที่ใช้ | **0 ฿** (ฟรีทั้งหมด) |
| SSL / สำรองข้อมูล / วิดีโอ | 0 ฿ (Let's Encrypt + Google Drive + YouTube unlisted) |
| **รวมต่อปี** | **~2,000–3,000 ฿/ปี** |

> จุดเดียวที่อาจมีต้นทุนในอนาคต: ระบบชำระเงินออนไลน์อัตโนมัติ (ค่าธรรมเนียม gateway) — ยังไม่จำเป็นในระยะเริ่มต้น

## 🛠️ สแตกที่ใช้ (ฟรีทั้งหมด)

WordPress.org (self-hosted) · ธีม Kadence (ฟรี) · Kadence Blocks · Custom Post Type UI · ACF Free · WPForms Lite · Download Monitor · UpdraftPlus · Wordfence/Solid Security · Joinchat (LINE) · Rank Math SEO + **ปลั๊กอินที่เขียนเองไฟล์เดียว** (ตารางสืบค้นเอกสาร, ดาวน์โหลด ZIP, สิทธิ์สมาชิก, directory ทันตแพทย์)

## ⚠️ ข้อห้ามสำคัญ (อ่านก่อนใช้ไฟล์ Stitch ใด ๆ)

1. ข้อมูลในตัวอย่าง Stitch เป็นข้อมูลสมมติทั้งหมด (ชื่อองค์กร ที่อยู่ เบอร์ ชื่อแพทย์ เลข ว. งานประชุม) — **ต้องแทนด้วยข้อมูลจริงของสมาคมก่อนเผยแพร่ทุกครั้ง** โดยเฉพาะชื่อ/เลขใบอนุญาตทันตแพทย์
2. โค้ด Stitch ใช้ Tailwind CDN — **ห้ามใช้ production** ต้องแปลง CSS เป็นไฟล์ในเว็บ
3. รูปทั้งหมดโฮสต์ที่ googleusercontent — ต้องโหลดมาเก็บเอง
