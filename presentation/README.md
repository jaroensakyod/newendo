# วิธีขึ้น Vercel — เว็บนำเสนอดีไซน์ 23 แบบ

โฟลเดอร์นี้เป็นเว็บ static ทั้งหมด (ไม่ต้อง build) ขึ้นได้ 2 วิธี

## วิธีที่ 1 — ลากโฟลเดอร์ใส่เว็บ (ง่ายสุด ไม่ต้องติดตั้งอะไร)
1. เปิด https://vercel.com/new (ล็อกอินด้วย GitHub/Google/Email ได้)
2. ในกรอบ "Deploy without Git" (หรือ Import Project) ให้**ลากโฟลเดอร์ presentation ทั้งโฟลเดอร์**ไปวาง
3. กด Deploy รอไม่ถึงนาที จะได้ลิงก์ เช่น https://tea-designs.vercel.app
   - หน้า Deploy settings ไม่ต้องแก้อะไร (Framework Preset: Other ก็ได้)

## วิธีที่ 2 — ใช้ command line
```
npm i -g vercel
cd C:\Users\ASUS\Desktop\newendo\presentation
vercel --prod
```
(ครั้งแรกจะถามล็อกอิน + ตั้งชื่อโปรเจกต์ ตอบค่าเริ่มต้นได้หมด)

## โครงสร้างไฟล์
- `index.html` — หน้านำเสนอ (หน้าปก + สารบัญ 23 แบบ + โหมดสไลด์เลื่อนได้)
- `designs/design-01.html ... design-24.html` — ดีไซน์ทั้ง 23 แบบ (ไม่มีไฟล์เลข 14 ตามต้นฉบับ)
  - ต้นฉบับยังอยู่ที่ `C:\Users\ASUS\Desktop\newendo\ตัวอย่าง\codeN.html` ไม่ถูกแตะ
  - แก้ดีไซน์ไฟล์ไหน: แก้ที่ต้นฉบับแล้วคัดลอกทับมาใน designs/ ด้วยชื่อเดิม

## ฟังก์ชันในหน้านำเสนอ
- เลื่อนแบบ: ปุ่มถัดไป/ก่อนหน้า, คีย์บอร์ด ← →, ปัดซ้าย-ขวาบนมือถือ, ลิงก์ตรงได้ เช่น `.../#d5`
- กรรมการกด "♡ เลือกแบบนี้" ได้หลายแบบ (เก็บในเครื่องผู้ชมเอง)
- กด "สรุปการเลือก" มุมล่างขวา → เห็นรายการ + ปุ่มคัดลอกข้อความส่งกลับ
- ลิงก์ตรงไปแบบใดแบบหนึ่ง: ต่อท้าย URL ด้วย `#d` + เลขไฟล์ เช่น `https://xxx.vercel.app/#d24`

## หมายเหตุ
- ข้อความ/รูปในดีไซน์เป็นข้อมูลตัวอย่างบางส่วน มีป้ายแจ้งกำกับไว้บนหน้าปกแล้ว
- เว็บใช้ Google Fonts (Noto Sans Thai) และฟอนต์/ไอคอน CDN ตามที่ไฟล์ดีไซน์ระบุ — ผู้ชมต้องต่ออินเทอร์เน็ต
